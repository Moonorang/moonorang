# 프로젝트 주제 및 요구사항 명세

챗봇으로 요금제 가입까지 모든 걸 해결하는 모바일에 맞춘 Next.js 프로젝트.

## 주제

- LLM API와 프론트엔드 채팅 화면 연동
- 사용자 요금제 가입과 관련된 질문을 입력할 수 있는 채팅 화면 구현
- 사용자의 사용량, 통화량, 예산, 부가서비스 선호 정보를 채팅 흐름 안에서 입력하거나 선택할 수 있는 기능 구현
- 입력된 조건을 기반으로 추천 요금제 목록을 채팅 메시지 또는 카드 형태로 표시
- 요금제별 월 요금, 데이터 제공량, 부가 혜택, 약정 조건 정보를 채팅 내에서 제공
- LLM 응답 생성 중 / 응답 완료 / 응답 실패 / 재시도 상황에 따른 화면 상태 처리
- 선택한 요금제의 가입 신청 정보를 입력하고 최종 가입까지 연결되는 채팅 흐름 구현

## 1. 기능 요구사항 명세 (Functional Requirements)

### common. 공통 화면 처리

각 기능 그룹에 공통 적용되는 요구사항으로, 개별 그룹에서 중복 기술하지 않는다.

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| COMMON-001 | 처리 시간이 1초를 초과하는 모든 동작은 진행 상태를 표시해야 함 | 필수 |
| COMMON-002 | 조회 또는 처리 실패 시, 발생 사유와 재시도 수단을 제공해야 함 | 필수 |
| COMMON-003 | 표시할 데이터가 없는 영역은 안내 문구와 다음 행동 수단을 제공해야 함 | 권장 |
| COMMON-004 | 처리 중인 요청에 대한 중복 제출 및 중복 요청을 차단해야 함 | 필수 |
| COMMON-005 | 모달 또는 바텀 시트 표시 중, 배경 영역의 스크롤을 차단해야 함 | 권장 |
| COMMON-006 | 콘텐츠 영역은 단일 열 레이아웃을 유지하며, 최대 너비를 제한하고 중앙 정렬해야 함 | 필수 |
